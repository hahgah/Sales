# Sales Data Analysis & Dashboard

Interactive dashboard analysing Superstore sales: trends, top products, regional profit and the effect of discounts.

**Tech:** SQL, Python, Pandas, Plotly, Streamlit

## What I did
Removed ~800 empty rows and duplicates, parsed dates, loaded data into a SQL database and answered business questions with SQL (GROUP BY, aggregations, ranking), then visualised results in Plotly.

## Results
See `sql_queries.sql` for the queries and the **Insights** tab for findings (e.g. deep discounts reduce profit).

## Run locally
```bash
pip install -r requirements.txt
# no training step needed
streamlit run app.py
```
